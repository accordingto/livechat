How to play
  1. Read the same prompt together. The host can change it before the holder (or host) lights the fuse. One prompt stays for the whole bomb.
  2. Say one fitting answer and tap PASS. A word, person, action, phrase, line or simple English description counts. Full grammar is optional. Funny earns no extra points.
  3. Avoid clear repeats this round; specific elaborations can count, and the next round starts fresh. For clear repeats or off-topic answers, another player can send it back while the fuse keeps running.
  4. The fuse is secret and random. Whoever holds the bomb when it explodes takes the card. Chat for 45 seconds, or move on early. The next card waits for someone to light the fuse.
  5. After the last card, the fewest bomb cards wins.
  6. Keep thinking if you get stuck; the bomb keeps running. Passing keeps the same prompt and fuse. Everyday knowledge or imagination is enough; personal stories are optional.
