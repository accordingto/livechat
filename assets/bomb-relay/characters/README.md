# Approved Bomb Relay art

These sixteen optimized transparent WebP assets are the user-approved v5
characters, expressions, running-leg atlases and classic bomb sequence.
The combined upper images include connected arms and hands; do not replace
them with the detached arm layers from earlier prototypes.

The classic `normal-bomb.webp` is a transparent cutout of the user's supplied
reference. The companion expressions/blast and character illustrations were
generated for this project. Original generated images and approval prototypes
remain in the local preview workspace; no private local paths are shipped.

`bomb-relay-art.js` owns measured source rectangles and joint coordinates.
The full atlases were scaled proportionally, so cropping uses their original
coordinate systems. The formal game uses this one metadata module and these
files directly. No duplicate editable preview catalog is loaded.
